# 客户端适配与验证

默认适配腾讯官方 Linux QQ 3.2.32，通过标准 X11 操作桌面窗口。构建从官方地址下载安装包，校验固定 SHA-256 和架构。客户端名称与窗口特征用于识别兼容软件，不是项目名称或图标。

## 手机画面

默认 `QQ_UI_SCALE=3`、`DESKTOP_WIDTH=4200`、`DESKTOP_HEIGHT=6000`。原生客户端、后端输入与网页裁切使用同一像素比例，手机按实际像素密度绘图，最高 3 倍。

聊天使用较窄的原生窗口重新换行，会话列表采用独立的 78% 比例，搜索栏保持原大小。背景和选中状态铺满网页，触点按各自比例映射。

群聊排除公告和成员列。后端校验发送按钮并及时重测裁切，截屏前后复核；前端等待会话、布局和画面一致后完成过渡。

完整画面生成有上限的高清滚动缓存，滑动移动合成图层。下一帧解码时仍可移动上一幅完整画面，新画面与坐标一起更新。后台、重连与全览会释放缓存。

## 搜索、输入与附件

点选搜索栏后由手机本地输入框唤起软键盘，提交后点选客户端结果，清空搜索内容后提交恢复列表。

发送前核对窗口、会话和输入，带有幂等请求 ID。未确认的内容按原会话保留，后续输入不会被旧响应清空。

图片粘贴取决于手机和来源 App 是否提供图片数据，无法粘贴时用“＋”选择照片或文件。附件发送前显示当前聊天标题供核对。

## 通知

后端只监听兼容客户端的标准桌面通知。静音会话、客户端焦点和手机系统设置可能影响真实提醒。配置见 [README](../README.md#可选消息推送)。测试通知不验证真实来信是否生成桌面通知。

## 客户端升级

固定版本使布局、发送确认和通知行为可复现。升级时不要只改下载地址而忽略校验值。先在独立目录构建，检查登录、切换、群聊裁切、滚动、搜索、连续输入、发送确认、附件、弹窗和通知，再替换原部署，保留回退镜像及备份。

## 真实账号检查

使用自己的测试会话，检查会话选择、返回与侧滑回弹、滚动、快速发送和恢复、图片与文件、菜单、断线恢复、锁屏测试通知和实际来信。

离线回归和部署脚本不向真实联系人或推送端点发送消息。具体账号、客户端和设备环境可能产生不同结果。
